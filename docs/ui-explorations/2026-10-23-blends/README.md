# Blends, 2026-10-23

Gallery and Margins spoke to the operator most (the [directions](../2026-10-23-directions/README.md)), so these are two
blends of them, each leaning one way. Same artifact, threads, and interaction as the directions, dark first with a
toggle for light, and set for a phone as Gallery was revised to be.

| File | Blend | Takes from Gallery | Takes from Margins |
|---|---|---|---|
| [annotated.html](annotated.html) | Annotated | The warm wall, the framed exhibit, its header, Fraunces and Source Serif, the oxblood accent | The conversation as numbered marginalia: no boxes, names in small caps, text links for actions |
| [open.html](open.html) | Open | Fraunces and Source Serif, the warm palette and oxblood accent, threads as placards | No frame: one column on the page, a single quiet line of chrome, the sidenote numbers |

What to compare: whether the page should sit in a frame (Annotated) or be the page (Open), and whether a thread should
read as a note in the margin (Annotated) or as a placard beside the text (Open). Either can take the other's answer to
one of the two.
